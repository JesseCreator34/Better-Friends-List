The Friends List isn't really good enough, so this mod fixes it by adding some new features like pinning (favoriting) friends and giving friends a nickname.

With Better Friends List you can favorite your friends wich pins them to the top of your friends list and give them a nickname in the new friends tab menu.

Current features:
- Pinning friends (favoriting them)
- Giving friends a nickname
- Viewing the full skin of friends

The next things that will be added to the mod are:
- Searching trough your friends list

This mod is still in Beta
When you've enabled Iris shaders and have not joined a world or server yet, the 3d skin preview will show inside out and bugged, this is an Iris shaders bug and will hopefully be fixed in the future.
